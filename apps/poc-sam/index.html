  • e2e.html: SAM tool on a synthetic gigapixel DZI (H2, H3)

Reproducing on real hardware

  1. pnpm install, then pnpm --filter @osdlabel/poc-sam fetch-models (real weights from npm and raw.githubusercontent.com; the random-weight architectures need the Python step it prints).
  2. Whole matrix, driving your desktop Chrome (real GPU for WebGPU): pnpm --filter @osdlabel/poc-sam bench -- --chromium "/path/to/Google Chrome" --headed (macOS: /Applications/Google Chrome.app/Contents/MacOS/Google Chrome; add --webgpu-models mobile_sam,sam2_tiny_real,efficient_sam_ti to measure WebGPU on more models).
  3. By hand: pnpm --filter @osdlabel/poc-sam dev, open the pages above on http://localhost (COOP/COEP are set, so crossOriginIsolated is true and WASM runs threaded), and use the console hooks.

Results go to apps/poc-sam/results/; pnpm --filter @osdlabel/poc-sam bench:summary <file> reprints the tables.
