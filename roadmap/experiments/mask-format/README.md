# Mask-format probes

The measurements behind the section on #149's mask format in [roadmap.md](../../roadmap.md) and the Mask format section of [evidence.md](../../evidence.md), kept as they ran on October 25, 2026, in a Linux container with Node 22. Each probe imports a copy of `@osdlabel/mask` compiled with `tsc` into a sibling folder that is not committed: `packages/mask/src` from #149 (`claude/segmentation-brush-tool` at 58a379f) for the "old" side, and from `claude/spike-mask-resolution` (70dd415) for the spike. Paths inside them point at that container.

| Folder      | What it measures                                                                                                                                                                                                                                                                    |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cap/`      | `cap-probe.mjs` drives #149's buffer the way the brush tool does on a 100,000 × 80,000 image (largest committable square, longest strokes, decoding an S1-sized box); `old-reader-probe.mjs` feeds coarser payloads to #149's decoder; `canvas-probe.cjs` checks over-wide canvases |
| `sparse/`   | Sparse 256 px tiles at full resolution against #149's run-length payload and a downsample field, for a mask built from S1's real frame (`synth.mjs`, `measure.mjs`), plus a dense reference and the brush cap; results in `results/`                                                |
| `tiled/`    | The tiled level-0 buffer prototype for the sparse option (a brush scribble at overview zoom, S1-like decode, overview and 1:1 renders), with its outputs                                                                                                                            |
| `option-a/` | The probe that checked the resolution field's chooser and whole-slide painting numbers                                                                                                                                                                                              |
| `critique/` | The reviewers' probes: old readers on 33 coarser payloads, COCO export bounds and round trips, the zoom-dependent brush rule (`ux.mjs`, `lazy.mjs`), and the multipolygon trace of the S1-like mask                                                                                 |
